# 오름오름 작업 규칙과 이어받기

새 세션은 이 문서만 읽고 시작한다. 구조·결정의 세부는 prototype-v1.md, 시안 결정은 background-sian.md · summer-sian.md · oreum-sian.md · namsongi-draft.md.

## 작업 규칙
1. 소스는 GitHub `spaceHWI/oreumoreum` 에 있다. 세션을 시작하면 `dev` 를 받아 `work/<작업 이름>` 브랜치를 만든다. 올리기가 거부되면 세션에 저장소를 추가해 달라고 한다
2. 세션 하나에 일 하나. 일이 끝나면 새 세션에서 다음 일을 한다
3. 동시에 여러 세션을 돌릴 때는 건드리는 파일이 겹치지 않게 나눈다 (풍경 `namsongi.js` / UI `page.html` / 시스템 `life.js`·`achievements.js`·`tutorial.js` / 시안은 `sian/` 만). `main.js` 는 한 번에 한 세션만
4. 확인은 빌드와 오류 확인(`tools/err.js`)까지. 스크린샷은 요청받았을 때만 찍는다. 모양은 사용자가 개발 서버에서 직접 본다
5. 끝낼 때: 커밋 → `work/` 브랜치 올리기 → 이 문서의 '지금 상태'를 고쳐 프로젝트 문서와 저장소에 같이 반영
6. "합쳐줘": `work/` 브랜치를 `dev` 에 합쳐 올린다 → 개발 서버에 자동 게시
7. "배포해줘": 버전과 릴리스 노트(`src/version.js`)를 정리하고 `dev` 를 `release` 에 합쳐 올린다 → 실서버에 자동 게시. 이 말이 없으면 `release` 는 건드리지 않는다
8. 시안을 만들면 소스를 `sian/` 에 넣고, 결정은 프로젝트 문서에 적는다
9. 멀티(여러 명 접속)는 claude.ai 아티팩트에서만 된다. 아티팩트 게시는 요청받았을 때만: https://claude.ai/artifact/7cea3use57e2Ag7tnrpeb7
10. 답변은 한글로, 짧게, 물어본 것만
