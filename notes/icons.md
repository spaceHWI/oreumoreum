# 아이콘 (#184)

아이콘 시트: `node tools/iconsheet.mjs <이름>` → `notes/shots/icons-<이름>-{phone,pc}.jpg` (세트·소스에 남은 손 그림·업적 뱃지를 한 장에)
- 바꾸기 전: `notes/shots/icons-184-before-*.jpg` (손으로 그린 선 그림 166개, 뱃지 30개)
- 바꾼 뒤: `notes/shots/icons-184-after-*.jpg`

## 구조
- `src/icons.js` — 아이콘 세트. **id 로 부른다**: `icon('bag')` → `<svg>`(또는 그림), `ic('bag')` → 안쪽 그림만(예전 SVG 틀에 넣는 곳)
  - 만든 곳 `tools/icongen.mjs` (손으로 고치지 않음). UI 는 Tabler Icons(MIT, `THIRD_PARTY.md`)에서 쓰는 것만 옮기고, 세트에 없는 오름오름 것(귤·하르방·정낭·클린하우스·집게·갈퀴·돌탑·귤 총 등)은 같은 24 격자·선 2 로 직접 그림
  - 새 아이콘: `npm i --no-save @tabler/icons@3.52.0` → `tools/icongen.mjs` 의 MAP(또는 OWN)에 한 줄 → `node tools/icongen.mjs`
- `src/page.html` 의 아이콘은 `<svg data-i="bag"></svg>` 로만 적고, 빌드(`build.mjs`)가 채움
- `src/iconart.js` — **그림으로 갈아 끼우기**: `ICON_ART = { gyul: '<주소>' }` 를 넣으면 그 id 는 선 그림 대신 그 그림(`icon()`·업적 뱃지). 그림은 `assets` 브랜치 `icons/` 에
- 물건(옷·도구·배낭·신발·무기·탈것)은 선 그림 대신 **실제 3D 모델을 찍은 그림** (`src/game/thumbs.js`): 처음 필요할 때 작은 렌더러로 한 번 찍어 캐시, 게임 시작 뒤 한가할 때 미리 찍음. 못 찍으면 세트 그림
- 업적 뱃지(`src/badgeicons.js`): 플랫 원(#20) 가운데 그림만 세트로, 단계 숫자(개근 3·7·30, 랭킹 10·1)는 오른쪽 아래 작은 원
- 글자 라벨(`src/game/iconui.js`): 위쪽 칸 아래 2~4글자, 폰의 줍기·상호작용·메뉴·동작 버튼 글자. 처음 3일 동안은 늘, 그 뒤엔 튜토리얼 뒤 10번 넘게 누를 때까지(`balance.js ICON_LABEL`)
- 크기: 버튼 안 24 안팎, 위쪽 칸 16, 선 2, 색 `currentColor`
